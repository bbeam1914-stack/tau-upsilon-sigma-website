# Tau Upsilon Sigma Website

Production website for Phi Beta Sigma Fraternity, Inc. — Tau Upsilon Sigma Chapter.

## Asset organization

- `assets/events/YYYY/<event>/` — event flyers and event-specific media
- `assets/gallery/YYYY/<event>/` — gallery photos and collages
- Root-level legacy/shared images remain temporarily for pages that still reference them; these will be migrated in controlled passes to avoid broken production references.

Do not commit passwords, API keys, private member records, financial records, scholarship applications, or other sensitive data to this public repository.

# Tau Upsilon Sigma Website

Production website for Phi Beta Sigma Fraternity, Inc. — Tau Upsilon Sigma Chapter.

## Asset organization
- `assets/branding/` — fraternity and chapter branding
- `assets/home/` — home-page imagery
- `assets/about/` — About Us imagery
- `assets/fraternity/` — regional/state fraternity imagery
- `assets/programs/` — program imagery
- `assets/scholarship/` — scholarship imagery
- `assets/membership/` — membership imagery
- `assets/events/<year>/<event>/` — event flyers/assets
- `assets/gallery/<year>/<event>/` — event gallery photography

Treat everything in this public repository as public information. Never commit passwords, API keys, member records, financial records, scholarship applications, or other sensitive data.
